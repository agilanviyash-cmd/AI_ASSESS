1.	The Decision Tree Classification experiment was successfully implemented using the Iris dataset and Python's Scikit-learn library. The dataset was loaded, inspected, and pre-processed by checking for missing values and ensuring that the input features were in a suitable numerical format. The data was divided into training and testing sets using an 80:20 ratio. A Decision Tree classifier was constructed using the Gini Index as the splitting criterion. The generated tree structure was examined, and the root node was identified as the feature providing the most effective initial split according to the Gini criterion. The trained model was used to predict the classes of the testing samples, and its performance was evaluated using accuracy, confusion matrix, precision, recall, and F1-score. The model achieved high classification performance on the Iris dataset, demonstrating that Decision Trees can effectively distinguish between the three flower classes based on their measured features. Any misclassified instances were examined by comparing their actual and predicted classes. Overall, the experiment demonstrates that a Decision Tree provides an interpretable and effective supervised learning approach for classification problems, although its performance can depend on the selected features, training data, and tree configuration.

2.	The Q-Learning experiment was successfully implemented using a 4×4 Grid World environment in Python. The environment consisted of individual states, four possible actions—Up, Down, Left, and Right—and a reward structure of +10 for reaching the goal, −1 for each normal movement, and −5 for encountering an obstacle. Initially, all Q-values in the Q-table were set to zero, and the agent learned through repeated interaction with the environment using a learning rate of 0.1, discount factor of 0.9, and exploration rate of 0.2. The Q-Learning algorithm was executed for 100 episodes, and the Q-values of two representative states were recorded at Episodes 1, 50, and 100. The comparison of these values showed that the Q-table gradually changed as the agent gained experience and learned which actions produced better long-term rewards. After training, the action with the highest Q-value in each state was selected to construct the final learned policy. The cumulative reward plot was used to observe the learning behaviour, where the agent generally improved its ability to reach the goal while avoiding unnecessary movements and obstacles. The experiment demonstrates how Q-Learning can learn an effective policy without being explicitly provided with the optimal path, making it useful for navigation, game AI, robotics, and other sequential decision-making applications.
