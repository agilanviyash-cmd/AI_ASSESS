1.	Water Jug Problem: We solved the Water Jug Problem using valid operations such as filling, emptying, and pouring water between the jugs. A Python program was implemented to achieve exactly 2 gallons in the 4-gallon jug.
The desired goal state was successfully obtained.

2.	Mars Rover Intelligent Agent: We analyzed the Mars Rover as an intelligent agent by identifying its percepts, actions, environment, and performance measures. A simple Python program was used to simulate the rover's decision-making process.
The rover successfully performed actions based on battery level and obstacles.

3.	8-Queens Problem: We solved the 8-Queens problem by placing eight queens on a chessboard without attacking each other. A Python program was implemented using the backtracking technique. A valid arrangement of all eight queens was successfully obtained.

4.	OLA Cab Booking (Goal-Based Agent): We simulated an OLA Cab Booking system using a Goal-Based Agent. A simple Python program was used to book a cab and calculate the fare based on the user's input. The booking process was completed successfully.

5.	Uniform Cost Search (UCS): We implemented the Uniform Cost Search algorithm to find the least-cost path in a weighted graph. A Python program was used to explore nodes based on the minimum cumulative cost. The shortest path and minimum cost were successfully determined.
