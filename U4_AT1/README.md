This project develops an AI-based healthcare decision-support system for early diabetes diagnosis and personalized treatment recommendation. The system applies supervised inductive learning to patient records containing age, blood pressure, cholesterol, glucose level, BMI, and family history, with diabetes status as the target variable. The data is divided into 70% training and 30% testing data using stratified sampling, and preprocessing includes missing-value handling, feature scaling, categorical encoding, and SMOTE-based class balancing. A Decision Tree classifier is developed using Gini Index to identify important diagnostic features, and its first three levels are visualized for interpretability. Accuracy, precision, recall, F1-score, AUC-ROC, and false negatives are used for evaluation, with special importance given to recall because missing a diabetic patient can result in delayed diagnosis and treatment. Cost-complexity post-pruning is applied to reduce overfitting and improve generalization. Logistic Regression is also trained as a statistical learning model and compared with the Decision Tree using Accuracy and AUC-ROC. Feature importance analysis identifies the strongest predictors and determines whether both models agree. Finally, treatment recommendation is formulated as a Markov Decision Process with patient health stages as states, Diet, Exercise, Medication, and Monitor as actions, and health improvement as the reward. A Q-Learning agent is trained over at least five patient episodes to learn an optimal treatment policy. Although the proposed system demonstrates how AI, statistical learning, and reinforcement learning can support healthcare decision-making, deployment in a clinical environment requires human supervision, patient safety mechanisms, bias testing, privacy protection, explainability, validation using real clinical datasets, and strict restrictions on autonomous medication decisions.
