1.	Rain and Wet Ground: The first problem demonstrates the use of resolution to determine whether the ground is wet when it is raining. The proposition R represents “It is raining,” while W represents “The ground is wet.” The rule “If it rains, then the ground becomes wet” is represented as R → W, which is converted into the CNF clause ¬R ∨ W. The given fact that it is raining is represented by R. To prove the goal W, its negation ¬W is added to the knowledge base. Resolving ¬R ∨ W with R produces W. The resulting clause W is then resolved with the negated goal ¬W, producing the Empty Clause □. Therefore, a contradiction is obtained from the negated goal, proving that the ground is wet. This example demonstrates how a simple implication and fact can be used to derive a conclusion through resolution.

2.	Student Assignment Submission: The second problem applies resolution to an academic assignment scenario. Let S represent “Rahul submitted the assignment” and M represent “Rahul receives internal marks.” The rule that if a student submits the assignment, then the student receives internal marks is represented as S → M. Converting this implication into CNF gives ¬S ∨ M. The fact that Rahul submitted the assignment is represented by S. The goal is M, so the negated goal ¬M is added to the clauses. Resolving ¬S ∨ M with S eliminates the complementary literals and produces M. Resolving M with ¬M then produces the Empty Clause □. Since the Empty Clause is derived, the negation of the goal is contradictory to the knowledge base. Therefore, it is logically proved that Rahul receives internal marks. This example shows how resolution can be used to automate logical reasoning in educational systems.

The given fact that Priya is a library member is represented as L. The goal is B, and therefore its negation ¬B is added to the knowledge base. Resolving ¬L ∨ B with L produces B. The resulting clause B is then resolved with ¬B, resulting in the Empty Clause □. Thus, the negation of the goal leads to a contradiction, proving that Priya can borrow books. This demonstrates the usefulness of resolution in rule-based library and information management systems.

4.	Placement Eligibility: The fourth problem demonstrates the application of resolution in a college placement system. Let A represent “Arun cleared the aptitude test” and E represent “Arun is eligible for placement.” The given rule is “If a student clears the aptitude test, then the student is eligible for placement,” which is represented as A → E. Its CNF form is ¬A ∨ E. The fact that Arun cleared the aptitude test is represented as A. The goal is E, so the negated goal ¬E is introduced. Resolving ¬A ∨ E with A produces E. The resulting E is then resolved with ¬E, producing the Empty Clause □. Therefore, the original goal is proved, and Arun is eligible for placement. The resolution tree consists of the first resolution deriving E from ¬A ∨ E and A, followed by the final resolution between E and ¬E to derive □. This example illustrates how automated reasoning can be applied to eligibility and decision-making systems.

5.	Access Control System: The fifth problem represents a more complex access control system involving two consecutive rules. Let P represent “The user entered the correct password,” A represent “The user is authenticated,” and G represent “The user is granted access.” The first rule, “If the user enters the correct password, then the user is authenticated,” is represented as P → A and converted into ¬P ∨ A. The second rule, “If the user is authenticated, then the user is granted access,” is represented as A → G and converted into ¬A ∨ G. The fact that the user entered the correct password is represented by P. The goal is G, so its negation ¬G is added to the knowledge base. First, resolving ¬P ∨ A with P produces A. Next, resolving ¬A ∨ G with A produces G. Finally, resolving G with the negated goal ¬G produces the Empty Clause □. Therefore, the original goal is proved, establishing that the user is granted access. This example demonstrates how resolution can chain multiple rules together to reach a final conclusion.
