1.	The A* Search Algorithm is an important Artificial Intelligence technique used for pathfinding and optimization problems. In this task, the algorithm was applied to a graph to find the shortest path from node A to node G. The algorithm combines both actual path cost and heuristic estimation to make intelligent decisions. By evaluating nodes using the function f(n) = g(n) + h(n), it ensures optimality and efficiency. The final optimal path obtained was A → B → E → D → G with a total cost of 8. This demonstrates how AI techniques can be used to solve real-world problems such as navigation and routing efficiently.

2.	The Minimax algorithm with Alpha-Beta Pruning is a fundamental Artificial Intelligence technique used in game playing scenarios. In this problem, the algorithm was applied to a game tree to determine the optimal move for the MAX player. The algorithm evaluates possible outcomes by simulating both players' moves and selects the best possible strategy. Alpha-beta pruning was used to eliminate unnecessary branches, improving efficiency. The final minimax value obtained was 3, and the best move was to choose the left subtree. This illustrates how AI can be used in strategic decision-making and optimization in games.
